buttons-mcp for Claude Desktop

Control Bitfocus Buttons (Stream Deck Studio) layouts from Claude Desktop. About the project

  1. Install the binary

    Download buttons-mcp for your OS from Releases and put it on your PATH, or build it with Go:

    go install github.com/Almiro-Studios/buttons-mcp/cmd/buttons-mcp@latest

  2. Log in to Buttons

    Saves your Buttons username and password in the system keychain. Run once:

    buttons-mcp login

  3. Add it to Claude Desktop

    Open Settings → Developer → Edit Config and add this to claude_desktop_config.json, then restart Claude:

    {
  "mcpServers": {
    "buttons": {
      "command": "buttons-mcp"
    }
  }
}

  4. Try it

    Opens Claude Desktop with a starter prompt prefilled. You review it before it runs.

    Open in Claude Desktop
