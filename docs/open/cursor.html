buttons-mcp for Cursor

Control your Elgato Stream Deck Studio through Bitfocus Buttons from Cursor. About the project

  1. Have Buttons running

    You need an Elgato Stream Deck Studio controlled by Bitfocus Buttons. Download Buttons, create the admin user at https://localhost:4443, add the Studio under Connect → Surface and create a Position. Full setup steps.

  2. Install the binary

    Download buttons-mcp for your OS from Releases and put it on your PATH, or build it with Go:

    go install github.com/Almiro-Studios/buttons-mcp/cmd/buttons-mcp@latest

  3. Log in to Buttons

    Saves your Buttons username and password in the system keychain. Run once:

    buttons-mcp login

  4. Add it to Cursor

    Add to Cursor

    Not opening? Install via cursor.com.

    Or add this to ~/.cursor/mcp.json:

    {
  "mcpServers": {
    "buttons": {
      "command": "buttons-mcp"
    }
  }
}

  5. Try it

    Opens Cursor with a starter prompt prefilled. You review it before it runs.

    Open in Cursor
